# EduQuest

For changes to Tutor AI, model routing, or provider configuration, read [the Tutor provider runbook](docs/ai-gateway.md). The current local provider is 9Router. Use the installed Vercel AI Gateway and Environment Variables skills when changing the optional Vercel configuration.

Keep provider calls in PHP on the server. Limit the model input to approved concept categories and help intents. Use validated choice indices to select existing hints. Exercise the offline path and the provider contract before changing a provider or model. Live checks may use credits, so use the explicit diagnostic command when a live test is authorized.
