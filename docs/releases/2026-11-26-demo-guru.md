# Demonstrasi guru pada pilot

Data berlabel demo menggunakan kelas XI PPLG A dan XI PPLG B yang sudah ada. `pilot-siswa` berada di kelas A; `pilot-teman` dan `demo-partner` berada di kelas B. `demo-guru` ditugaskan ke kelas B dan memiliki dua kuis demonstrasi. Password akun demo disimpan terpisah dari repository.

Gunakan kuis **Latihan Logika Pemrograman Kelas B** untuk menunjukkan soal, pembahasan, dan contoh nilai sintetis 75. Siswa kelas A tidak dapat membuka kuis ini. Pada halaman kuis guru tersedia ekspor nilai serta soal dan kunci, masing-masing dalam PDF atau XLSX. Dokumen soal dan kunci hanya untuk guru, jangan dibagikan ke siswa sebelum pelaksanaan.

Quest demo aktif selama tujuh hari sejak dibuat. Mastery memiliki contoh dikuasai, tersedia, dan terkunci; Susun Langkah menyediakan latihan contoh. `pilot-teman` dan `demo-partner` dapat digunakan untuk mencoba PvP dalam kelas B. Semua hasil contoh diberi label demo dan tidak dimaksudkan sebagai nilai akademik.

Jalankan `node tests/run.mjs demo-fixture`, `node tests/run.mjs teacher-export`, dan `node tests/run.mjs teacher-export-http` dengan konfigurasi PostgreSQL uji. Ekspor dibatasi hingga 5.000 baris dan tidak diam-diam memotong hasil. PDF memakai dompdf dengan akses resource remote dan PHP tersemat dinonaktifkan; XLSX menyimpan input teks sebagai teks dan nilai sebagai angka.
